# Portfólio de Sarah Alencar — v1 e v2

Este repositório reúne o código HTML do portfólio pessoal e o estudo de design da atividade “Recuperação de um projeto existente” do IFSP Guarulhos.

## Versões completas

- [v1-portfolio.zip](v1-portfolio.zip): cópia do projeto antes das intervenções.
- [v2-portfolio.zip](v2-portfolio.zip): projeto atualizado, com HTML, CSS, JavaScript, imagens, `PRODUCT.md`, `DESIGN.md`, catálogo e registros.

Os arquivos HTML principais também estão disponíveis individualmente para leitura: [v1](index-v1.html), [v2](index-v2.html), [catálogo dos 23 comandos](catalogo-impeccable.html) e [registro de 14 aplicações](aplicacoes-impeccable.html). Os arquivos CSS e JavaScript da v2 estão no repositório; para executar o site com os caminhos e imagens corretos, extraia o ZIP correspondente.

## Site publicado

[Abrir o portfólio v2](https://portfolio-sarah-alencar.sarahandradealencar.chatgpt.site)

## Verificação

A v1 foi preservada antes das mudanças no histórico do projeto original. A v2 foi comparada visualmente em largura móvel e ampla, nos temas claro e escuro. Uma varredura técnica inicial apontou 32 observações; depois das correções, restaram 17, sem avisos de baixo contraste. O registro de aplicações descreve objetivo, evidência, resultado e decisão de cada intervenção. Não foram feitos testes com participantes.
